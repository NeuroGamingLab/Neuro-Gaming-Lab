# Neuro Gaming Lab

**Neuro Gaming Lab dares to dream:** games and AI as playgrounds for ML, RL, and agentic systems—we **ignite innovation**, **strive for excellence**, and **explore together** to **unlock the world's knowledge**.

[Browse all repositories on GitHub →](https://github.com/NeuroGamingLab)

---

## What the lab is

Neuro Gaming Lab is an open engineering and research footprint across **playable AI**, **synthetic neuro signals**, **collective intelligence**, and **agentic tooling**. We use small, legible worlds (arcade classics, simulators, dashboards) to make learning and evaluation tangible—then connect those worlds to the bigger stack: retrieval, local models, multi-agent runtimes, and safety-minded workflows.

This repository (**Neuro-Gaming-Lab**) is the lab’s **public hub**: narrative, GitHub Pages site under `docs/`, and media that introduce the mission. Implementation code lives in the sibling repos listed below.

---

## Dare to dream

We treat imagination as a first-class engineering input. Games become **living sandboxes** where hypotheses meet pixels and physics; **software-generated brain-like signals** let us prototype neuro-informed pipelines **without EEG hardware**; agents and orchestrators let us ask what “good collaboration” looks like before we bet the farm on a single stack.

Dreaming is how we choose problems worth solving.

## Ignite your inspiration and innovation

- **Adaptive arcade AI** — Deep nets, RL, MARL, and agentic behaviors embedded in beloved titles: smarter ships, ghosts that hunt in packs, enemies that predict and flank, frogs and roads that fight back with planning and adversarial spice.
- **Neuro signals in software** — [Neuro-Brainwaves-ML](https://github.com/NeuroGamingLab/Neuro-Brainwaves-ML) generates plausible **multi-channel waveforms** (delta–gamma, labeled states such as relaxed or focused), **Streamlit** dashboards, producer/consumer flows, and an optional **`neuro_brainwave_ai_project/`** path for deeper experiments and forecasting-style components—**no headset required** ([repo overview](https://github.com/NeuroGamingLab/Neuro-Brainwaves-ML)).
- **Knowledge and models** — [Neuro-Chat](https://github.com/NeuroGamingLab/Neuro-Chat) is a web UI for collective intelligence (LangChain + FAISS, Ollama-backed answers, optional prompt safety, indexes that can strengthen from summarized Q&A). [Comparison-Models-Lens](https://github.com/NeuroGamingLab/Comparison-Models-Lens) compares how different models respond to the same prompts.

When a ship dodges smarter, a trace on the screen teaches frequency bands, or a retrieval index improves after a session—that is **inspiration catching fire** in code.

## Strive for excellence

Excellence is **rigor with joy**: reproducible runs, honest metrics, interfaces that respect players and researchers, and patterns (like configurable output paths and local dataset generation) that keep repos **auditable and clone-friendly**. We bridge **preservation** and **frontier AI**—small worlds can still demand serious algorithms and disciplined ops.

## Explore together & unlock the world's knowledge

Knowledge grows when it is **shared**. We invite collaborators, students, and curious builders to fork, run, and extend the repos below—every issue, demo, and doc is part of the same **explore together** loop.
